
AI GUITAR STUDIO 3.0.0
=====================

Автор: UA Server
Сайт: https://uaserver.pp.ua

ВСТАНОВЛЕННЯ
------------

1. Створи папку:

   ai-guitar-studio

2. Розмісти файли за такою структурою:

   ai-guitar-studio/
   |
   |-- ai-guitar-studio.php
   |
   |-- assets/
       |
       |-- css/
       |   |
       |   |-- studio.css
       |
       |-- js/
           |
           |-- audio-engine.js
           |-- pitch-shifter.js
           |-- chord-analyzer.js
           |-- stem-separator.js
           |-- lyrics-recognition.js
           |-- translation.js
           |-- collection.js
           |-- studio.js
   |
   |-- README.txt

3. Завантаж папку в:

   wp-content/plugins/

4. Увімкни AI Guitar Studio в адмінці WordPress.

5. Створи сторінку, наприклад:

   AI Guitar Studio

6. Додай на сторінку шорткод:

   [ai_guitar_studio]

7. Опублікуй сторінку.

ПОТОЧНІ МОЖЛИВОСТІ
------------------

- Завантаження аудіофайлу з пристрою.
- Відтворення оригінальної композиції.
- Завантаження прямого аудіопосилання за умови підтримки CORS.
- Отримання тривалості та характеристик аудіо.
- Попередня оцінка тонального центру.
- Попередня оцінка темпу.
- Експорт аудіо у WAV.
- Особиста колекція користувача WordPress.
- Збереження назви та нотаток.
- Збереження попередньої оцінки тональності.
- Пошук і сортування колекції.
- Видалення композицій.
- Редагування нотаток.

ЩО ПОТРЕБУЄ ОКРЕМОЇ РЕАЛІЗАЦІЇ
-----------------------------

1. Транспонування без зміни швидкості:
   потрібен повноцінний pitch-shifting алгоритм.

2. Розділення вокалу:
   потрібна AI-модель та її інференс.

3. Розділення гітари:
   потрібна AI-модель, яка підтримує відповідну доріжку.

4. Розпізнавання співу:
   потрібна модель транскрибування аудіофайлів.

5. Переклад українською:
   потрібна окрема модель або сервіс перекладу.

6. Синхронні акорди:
   потрібна модель визначення акордів із часовими мітками.

7. Схеми акордів:
   потрібна бібліотека аплікатур із відображенням струн,
   ладів та положення пальців.

ВАЖЛИВО
-------

Поточна версія не повинна показувати, що AI-обробка вже працює,
якщо відповідні моделі не встановлені.

Збереження колекції здійснюється в метаданих поточного
облікового запису WordPress.

Збережені записи не містять самих аудіофайлів.
